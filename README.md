# Valkrie-Script

Repo ini berisi script Valkrie dan source website **Valkrie Tools**.

## Website Valkrie Tools

Kode website ada di folder [`Valkrie-Tools`](Valkrie-Tools/). Mulai dari [panduan edit dan preview](Valkrie-Tools/README.md) untuk menemukan file produk, tampilan, dan navigasi.

- Data produk dan kategori: `Valkrie-Tools/data/products.ts`
- Komponen halaman utama: `Valkrie-Tools/components/Storefront.tsx`
- Gaya website: `Valkrie-Tools/app/globals.css`
